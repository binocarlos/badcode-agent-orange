# Assets

`agent-orange.svg` is the README banner — hand-drawn vector, no dependencies, renders in both
GitHub themes. The mark is the metaphor: an orange whose **segments are workers**, whose **walls are
the fact that workers never talk to each other directly**, and whose **core is the shared memory
every segment touches**. Six workers, one core. That is the whole architecture.

To replace it with something richer, keep that reading. A hero image that shows agents wired to
each other in a mesh would be showing the wrong system.

## Prompts for an image model

Written for an image generator (Imagen / Midjourney / DALL·E). Each is standalone; the first is the
one to try first. Aspect ratio 15:4 for a banner, or 1:1 for a social card.

**1 — The mark, rendered properly (recommended).**
> A cross-section of a single orange on a deep near-black warm brown background, photographed from
> directly above, studio lighting. The fruit's segments are clean and geometric rather than
> organic — eight equal wedges separated by crisp dark walls. At the very centre, where the pith
> would be, a small glowing amber core. A single tiny dark seed sits in each segment, equidistant
> from the core. Rich saturated orange, deep shadows, high contrast, minimal, editorial product
> photography, no text, lots of negative space to the right.

**2 — The same idea, flat and diagrammatic.**
> Minimal flat vector illustration, wide banner. A stylised orange cross-section as a perfect
> circle divided into eight wedges by thin dark lines radiating from a glowing central node. One
> small dot per wedge, all the same distance from the centre, each connected to the centre by a
> faint line — and no lines between the dots. Warm orange gradient on near-black. Swiss graphic
> design, geometric, no text, generous empty space on the right third.

**3 — Warmer and more atmospheric.**
> A halved orange resting on dark slate, lit by a single warm low sun from the left, long soft
> shadow stretching right. Dust in the air catching the light. The cut face glows slightly from
> within, as if lit from behind. Moody, cinematic, shallow depth of field, muted background,
> nothing else in frame. Colour palette: burnt orange, amber, deep brown, near-black.

**4 — Social card (1:1).**
> A single orange segment, isolated on near-black, backlit so the flesh glows amber and the
> membrane reads as a fine dark lattice. Macro photography, extreme detail, dramatic rim light,
> minimal composition, centred.

**Avoid:** military or defoliant imagery (the name is a joke about a colour, not a reference);
robots, humanoid faces, circuit boards, glowing blue holograms, or a network mesh of connected
nodes — the mesh in particular is the architecture this project deliberately does *not* have.
